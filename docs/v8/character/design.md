# 烁羽 V8：受光层次与动作重量

本轮用户实测指出强光失真、走得慢、无法停栖和运动方式不够丰富。角色工作保留烁羽的原创身份、玉绿覆羽与微金羽缘，先验证真实光照下的材质响应，再扩充动作。主控制器与交互优先级由其他模块负责。

## 排查与取舍

1. 不把整体曝光压暗当作角色修复：保持同一镜头和灯光，比较羽材的漫反射、sheen、粗糙度、法线和湿态高光。V7三层羽材均有较高sheen，需区分正常边缘绒光与整块白色反光。
2. 不靠增加羽片数量解决程序化：保持几何预算，改善胸腹/肩背的层次、毛流和亮暗变化；近景与主游戏距离都要检查。
3. 运动仍使用原有8种物理模式，用额外dashing/dashProgress/cruise/perchApproach/gait状态形成动作层，避免新枚举导致旧脚步、声效和水体状态失效。

## 动作设计

- 普通步行约2.2m/s，快走约3.9m/s：让步长与落足接触匹配速度，保留鸟式头部稳定和侧向重心移动。
- 闪身：短促压身、羽翼收拢、尾羽定向；空中更流线，地面采用一次跨步而不是超高速踏步。暂停冻结，结束后恢复正常落足。
- 持续飞行：巡航采用较慢的振翼节奏与较长的回收阶段，保持真实下拍事件，不额外按计时器造翼声。
- 枝头：清晰收翼与蹲身、趾握，保持枝头主体与足底可读。

## 验证

冻结V7源和GLB作基线；同曝光多光位/湿态A/B；实际高低LOD载入；所有动作切换与暂停、骨骼有限数值、羽尖/脚底真实蒙皮坐标、接地和收腿空间检查。只在同机、同脚本中报告CPU动作更新成本，角色局部帧率不当作全游戏帧率。

实现与证据更新在此目录。专业高模烘焙、逐羽物理和动作捕捉仍不在现有资产内，不以程序细化冒充这些制作工序。

## 第二轮近景依据

首轮母版修正了颈根套筒式交界，但肩根平切翼核、侧颊过长羽尖和胸腹横排仍有程序片状感。第二轮保持816根躯干羽的数量，改连续螺旋分布、缩窄贴合；短羽纵向采样向末端集中以改善同面数下的轮廓。翼核上下端连续收尖，外覆羽同步贴合；侧颊羽缩短向后梳理。眼球底、虹膜、瞳孔不再同时使用强镜面层，保留外角膜与小捕光。

- [Cornell Lab 羽毛结构](https://academy.allaboutbirds.org/feathers-article/)：覆羽应形成连续外轮廓，松软根部与互锁羽枝的外端承担不同作用。本作据此区分绒底、短覆羽和飞羽，不复制其照片。
- [美国鱼类及野生动物管理局 Feather Atlas 术语](https://www.fws.gov/lab/featheratlas/glossary.html)：重叠体羽形成平滑的气动外形；用于检查翅根不能表现为裸露竖板的判断。
- [Disney Physically-Based Shading](https://www.disneyanimation.com/publications/physically-based-shading-at-disney/)与项目Three.js 0.185物理着色源码：把基础粗糙反射和边缘sheen作为不同层进行试验。没有移植该论文代码，也不声称本作实现完整羽毛散射模型。

固定光照实验记录了曝光不变的局部截图。像素统计只描述这些机位，不代表所有游戏镜头。测试脚本直接拦截实际GLB响应并检查V7/V8元数据，避免Vite优化模块与原始GLTFLoader是不同类时，prototype替身未生效导致错误A/B。

## 第三轮：连续羽区与真实枝头支撑

第二轮实页比较显示，打散横排之后，短覆羽的17%根部色差和底绒/覆羽不同sheen又形成不规则亮斑。第三轮保留数量与拓扑，收窄短羽色差、使相邻层材质响应接近，保留长飞羽独立的羽轴层次。头顶普通覆羽收短、压低，保留三根标志冠羽。曾尝试沿头骨连续扫掠，但近景出现新的暗缝，因此未保留这一实验；没有为了去尖角接受更差的头顶视觉。腹后轮廓细羽使用所在羽区的玉绿色；翅内副飞羽略收窄并形成连续弧面。

停枝不能只验证模式切换。真实蒙皮CPU诊断发现旧形变使前趾距参考枝面至少35mm，而后趾局部穿入9.4mm。按实际落枝半径0.29m重建趾底弧面，去除额外抬足与翘脚，初步变为前趾4.2mm、后趾8.4mm的正间距。主枝斜率来自同一CatmullRom曲线的真实切线；主控制器透传世界梯度，角色在当前朝向下分别计算左右足高与脚掌倾斜。任意斜枝及π等价朝向的CPU圆柱检查、第三轮真实弯枝近景以及后续主线程最终资产实际停枝记录均已完成；各轮次与证明范围见[最终验收记录](verification.md)。

持续振翼采用44%下拍、56%回收，保持下拍中点在原phase=.5，声音事件因此继续对应负载最大阶段。翼腕与五组主飞羽沿同一非均匀相位延迟，避免肩膀和羽尖的时序互相脱节。

真实枝头近景又暴露出旧模型的跗跖骨与脚趾之间没有关节体积。最终补入中心与Foot骨同位的圆关节，保证转足时接合；腿和趾上的小圆管装饰改为贴合表面的弧形角质鳞片，沿用原材质与骨骼。

第四轮肩根最终采用连续胸肩轮廓和16根连接既有翼骨的短覆羽，未保留实拍中显得突兀的外加肩球。闭合UV接缝法线在生成阶段焊接，实心表面的源三角朝向另经CPU独立轴线/中心检查，两档均无反向面。最终资产为107,222／46,722三角、33骨、12材质，于2026-11-19 07:43:44 UTC导出冻结。20张同灯比较、15个最终动作/近景样本、55项五枝交互专项与最终资产实际游玩截图的时间口径及剩余局限，统一记录于[verification.md](verification.md)；较早专项不视为最终GLB的完整重跑。
