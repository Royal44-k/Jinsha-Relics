# 金沙探索游戏 V2：角色、文化依据与声音导演方案

研究日期：**2026-11-18（Asia/Shanghai）**。状态：设计研究与建议，未制作或采购新模型、音频；没有录制文物原声。文中“建议”“原创设定”均是创作选择，不是考古结论。只读检查了当前 `src/audio.js` 和调用处。

## 1. 先确定文化边界，再塑造角色

| 可核实事项 | 研究结论 | 对设计的影响与来源 |

## 2. 三个原创角色方向

以下所有名字、性格、尺寸、动作与能力都是本项目的虚构提案。

| 方向 | 形体与材质 | 性格和动作 | 声音 | 玩法价值与取舍 |
|---|---|---|---|---|
| **A · 烁羽／听光的羽灵（推荐）** | 小型活体鸟灵；昂首圆眼、短而灵巧的尖喙；冷青绒羽与暖象牙胸羽，三片不等长的薄金尾羽；胸前只有一处琥珀色微光，身体保留阴影与体积 | 好奇、稍有胆怯，却会自己迈出第一步；落地先收翼、前倾听声，起飞有蹬地与抬胸，转弯先看再偏翼；受惊轻缩颈，不靠不断卖萌 | 青年感中性声，清澈、近距离、略带气息；短句；情绪变化由表演而非强行升调。无对白时偶有两音短鸣 | “侧光显纹”“驻足听音”“逆风滑翔”三者可以构成探索，而非只有飞行。与太阳/鸟/金箔形成清晰联系；羽毛、翅膀绑定和表情制作成本较高，但主角值得集中投入 |
| B · 砚生／听石的守路者 | 小型石兽，灰黑天然纹带；额间一枚浅玉感细纹；落地可见重量，短距跃起而不无限悬浮 | 稳重但不无所不知；蹲伏、嗅地、耳侧听、缓慢扭头 | 偏低而柔的青年声；句末短促呼气，动作配石屑细响 | 触地回声寻找暗道、踩压机关；地面探索很强，飞行幻想较弱，与原片灵鸟识别距离大。石虎的“守护”只作为本作设定 |
| C · 金汀／雨岸的蛙灵 | 小型两栖精灵，湿润但克制的皮肤高光，金箔般折线四肢饰边；背部水滴反射，不全身黄金 | 机警、淘气；短跳、蹲踞、鼓动喉囊、落水收腿，节奏有停顿 | 轻快而不尖细，偶有低短的非语言咕音；由演员表演而非替换成动物叫声 | “听雨识径”“浮叶借力”“水面倒影拼合”很新颖，也贴合滨河环境；但偏水域作品，较难承接太阳神鸟主线 |

### 推荐主角的制作标准

- **剪影先于装饰**：缩至屏幕高度80像素时，仍能分清头、喙、胸、翅与折尾；不能再次做成被辉光吞没的白色葫芦。金色集中在尾羽和眼部反光，不铺满身体。
- **生物结构**：头颈、胸骨、翼根有明确运动关系；停下时身体有呼吸，眼睛有可控注视和眨眼。翼根不是两块悬空椭球，尾羽不能直接穿模。
- **PBR雕刻交付**：先做正侧背三视图与体块灰模，再高模雕刻、重拓扑、UV、烘焙法线/粗糙度、绑定、动画。用有方向的羽片与局部绒毛卡片形成材质，环境光和主光关闭时仍可看清造型。概念图不能冒充已经可用的绑定模型。
- **最小动画集**：呼吸待机、左右观察、驻足倾听、起飞、巡航、滑翔、转弯、刹停、落地、惊讶、共鸣、疲惫；运动过渡要接续速度，不随机切动画。
- **小而有缺点**：它能看见短暂光纹，却不认识所有道路；它害怕完全无声的黑暗。玩家的观察使它逐渐勇敢，形成双向陪伴，而非一位知道全部答案的导航器。

### 首页角色资料卡建议

首页只露出当前林间入口与近景烁羽，不预览整个世界。角色可主动看向光标、缩翼避雨；点击“认识烁羽”才打开资料卡。

资料卡分为：①转台近景和三个动作；②姓名“烁羽”、身份“记忆之境的听光者”、一句愿望“我想知道，雾后面还有什么”；③三项能力及可操作的短演示；④“设计从哪里来”的铜鸟/神鸟/金箔研究链接；⑤声音试听“轻声／惊讶／鼓起勇气”。后两项明确是设计依据与原创声音，不能标“金沙真实小精灵”。

首页人物小传草案：

> 烁羽是在金色余光中醒来的羽灵。它记得羽翼该朝哪里展开，却忘了天空有多远。每当你停下来倾听，胸前的微光就会回应那些被遮住的纹路。它不是你的向导；你们将一起学会穿过雾。

## 3. 音乐应有古蜀依据，但不伪造古蜀原声

**有直接依据的音色锚点：**金沙馆方发布的铜铃条目描述小型合瓦形铜铃，部分没有铃舌；官网报道明确提到金沙出土石磬及复制品互动展示。这足以支持以“金属余响、石质敲击与礼仪空间感”展开原创配乐。[铜铃馆藏条目](https://artsandculture.google.com/asset/bronze-bell/jAEx2apytSzZIA?hl=zh-cn)、[石磬官方展讯](https://www.jinshasitemuseum.com/info/2029)

**尚无本次研究可证明的内容：**金沙音乐的完整曲谱、固定音阶、配器组合、演奏节拍，以及上述铜铃/石磬可合法使用的实物采样文件。不能把现代五声音阶、某个D调正弦泛音、任意“国风”曲目或川剧声腔称为三千年前金沙的真实BGM。川剧等可用于当代成都主题，但不适合作为本作古蜀场景的默认时代证明。

**创作方向：**“金石余音与湿润林地的呼吸”。避开从头到尾的大编制史诗音乐。大量留白，让玩家先听到门后的水声，才在转弯处见到溪谷；开阔画面到来时才释放主旋律。现代弦乐、低笙感持续音或气声管乐如被采用，注明为当代配乐选择。

### 动态配乐分层（制作提案，非历史还原）

| 层 | 听感与功能 | 何时出现 |
|---|---|---|
| 环境底层 | 近处叶片、远处水流、空间风声；声源有方位与遮挡感 | 常驻，但按所在区域替换；转角先透出下一地区的声音 |
| 记忆底层 | 很弱的低持续音、呼吸式起伏，无明确鼓点 | 初入未知、雾区；让探索保留不安和期待 |
| 金石动机 | 石质短击与铜铃长尾的两至四音回应 | 靠近遗物/光纹，听清后可循声靠近；不要整段机械循环 |
| 行进层 | 稀疏低鼓、木质颗粒，速度变化不直接机械改变整首曲速 | 确认向前进入新路、滑翔；驻足时退出 |
| 角色主题 | 简短可哼唱旋律，以柔和拨弦或气声表现；后期由不同音色回应 | 首次角色介绍、鼓起勇气、意外发现；避免每次拾取都重复整段 |
| 开阔层 | 宽声场和声、金石高频亮点与主题完整句 | 玩家真正穿出遮蔽看见新地点，高潮长度约8—15秒后回落 |

第一章节奏例：入口近雨与一声孤石→狭道音乐收窄、角色轻声→岔路远处水声引导→转角短暂静默→阳光穿入后才进入完整主题→文物旁音乐让位给解说。惊喜来自“先少后多”，而非持续最大音量。

工程建议：预制同步分轨而不是用 `setTimeout` 随机弹音；按探索状态启动、交叉渐变并在拍点连接。以 `exploration / listening / threshold / reveal / dialogue / menu` 为状态，旁白或对白播放时自动压低音乐与高频环境层；角色与旁白共享排队系统且互不叠读。字幕由实际音频的时长和cue表驱动；单独提供BGM、环境音、对白三条音量。关键线索必须有视觉等价提示，不能要求只凭听觉通关。

## 4. 两种声音的导演规范

| 项目 | 烁羽（玩家角色） | 录忆者（旁白，工作称呼） |
|---|---|---|
| 身份 | 刚学会面对未知的原创羽灵 | 当代知识视角的叙事声音；不是声称来自古蜀的真实祭司 |
| 声线 | 青年感中性、明亮但不尖、亲近，呼吸自然；少量句尾笑意 | 成熟女中音或低中音，温暖、有颗粒，语速从容；像和同行者谈一件珍贵物品 |
| 表演 | 惊喜先吸气，害怕压低声量；鼓起勇气时句首短停，随后更坚定 | 事实句清楚，推测句保留语义；不故作神谕、不把所有词拖长 |
| 空间 | 更近、更干，轻微场景反射；短鸣仅用于没有台词的动作 | 声像稳定居中，极轻房间感；不加模糊咬字的大混响 |
| 文案职责 | 感受、发现、犹豫、邀请玩家行动；每句通常6—18字 | 提供必要事实、对比和意义；一次最多两句，避免边前进边朗读长图鉴 |
| 辨识方式 | 固定表演者/固定原创合成声线；角色专属两音轻鸣可作无语言招呼 | 固定另一表演者/另一声线；不靠同一系统TTS的pitch参数区分 |

不模仿具体知名演员或馆方数字人的声线。四川地域亲近感可用自然用词和温和节奏体现；若加入方言，作为当代创作而非“古蜀发音复原”。

### 第一章8句原创对白样例

| 触发条件 | 说话者 | 台词 | 表演与调度 |
|---|---|---|---|
| 玩家第一次控制角色 | 烁羽 | “醒了？我也是……刚刚。” | 轻声，停顿后自嘲一点点；不要挡住首次操作 |
| 入口转角露出微光 | 烁羽 | “那道光，在等我们吗？” | 好奇，转头与凝视先发生，再说话 |
| 第一次驻足听音 | 录忆者 | “先别急着看见。听，水声从石壁后面绕了过来。” | 这是场景引导，不冒充文物知识 |
| 接近昏暗狭道 | 烁羽 | “有点黑。我们一起，好吗？” | 克制畏惧；说完继续由玩家决定前进 |
| 绕过遮蔽首次看到溪谷 | 烁羽 | “原来，路藏在这里！” | 一次真正的惊喜，之后留4秒环境声 |
| 首次观察铜鸟 | 录忆者 | “金沙铜鸟昂首、收翼，尾羽折而下垂。小小的造型里，有一种向上的力量。” | 前句基于馆藏形制，后句为审美解读；图鉴可展开来源 |
| 光纹首次显现但方向未明 | 烁羽 | “我照亮这一小段。剩下的，我们去找。” | 自信增加；不直接说出终点坐标 |
| 章节结束、下一道门半启 | 录忆者 | “留下一件器物，也留下一个问题。下一次相遇，会从你的下一步开始。” | 主题性原创句；片尾旋律接住尾音 |

8句是导演试音脚本，不是已录音资产。评审时必须先听两位声音的同文试听和上下文对白，再锁定长段生产；只看供应商“支持中文”不能证明实际咬字与情绪合格。

|---|---|---|
| `audio.js::_ambience()` | 循环噪声与持续正弦音始终使用同一组合 | 使用有地点身份的环境分层与空间发声点，依据狭窄/开阔区域调节 |
| `audio.js::_scheduleMelody()` | 约6.5—12秒随机播放一个固定序列音符；没有段落、同步分轨或区域状态 | 做主题、过渡、静默与揭示；音乐状态与玩家行为绑定，而非随机提示音承担全部BGM |
| `audio.js::speak()` | 选系统第一个中文声线，固定语速和音高；新话语调用会取消旧话语 | 角色和旁白使用明确资产ID、说话者、cue、优先级和可中断策略，声音跨设备保持一致 |
| `main.js::subtitle()` | 字幕定时消失，与实际语音时长无关 | 同步音频时间轴；提供字幕历史与重播，暂停时一致停止 |
| `audio.js::_scheduleMelody()`与语音 | 说话时只跳过新的旋律点，已有底层未做统一压低 | 对话总线触发BGM/环境侧链式ducking，播毕缓慢恢复 |
| `main.js`移动分支 | 飞行中周期调用`footstep()` | 区分地面步伐、起飞、振翅、滑翔风与衣羽摩擦；不能悬浮时仍响碎石脚步 |
| 设置 | 仅统一音量与可选系统旁白 | 音乐/环境/对白独立音量，字幕默认可用；角色台词开关和旁白开关分开 |

## 7. 下一步的可验收声音与角色包

第一轮先完成角色三视图、转台灰模、3个表情和3个动作样例；对照文化形制和侧后方游戏镜头审查，不只看正面海报。之后才扩展完整绑定与动画。

声音先交付一段45—60秒“入口—狭道—显现”的可听样片，包含两种声线、动态BGM、环境声、一次声画同步揭示；盲听应能区分两位说话者，听清对话且不会被铜铃高频刺耳打断。它是判断品质方向的依据，不用大批量低质量占位音频替代。

内容包需包含：原始与游戏压缩音频、曲目分轨与循环点、角色/旁白cue表、完整字幕、音频授权记录、角色模型/贴图/绑定/动作清单。正式交付时再验证跨设备播放、首次点击启音、静音恢复、对话不重叠、跳过和暂停行为。
