# 金沙 V2：学习笔记与设计决策依据

日期：2026-11-18。状态：研究成果，未改变现有游戏。用户已确定浏览器优先。

## 这次必须吸取的经验

1. **能通关不是精良。** V1自动流程通过，只能证明收集/解谜等功能闭环；没有证明模型、空间惊喜、角色表演、混音达到目标。V2分开做功能、视觉、声音、探索体验四类验收。
2. **程序分析不等于艺术理解。** 3314帧指标有助定位镜头变化，必须补上关键帧构图、空间遮挡、节奏与玩家能动性的分析。参考视频是基础框架，不锁死场景或美术。
3. **全世界一起创建，会同时破坏惊喜与加载。** 当前全局合批、全图标记、30单位飞高、自动直达，一起让玩家在开始时已知道世界大小。改成连通空间、遮挡、有限滑翔、已探索地图与局部引导。
4. **发光不能代替雕刻。** V1球锥组合被照成白团，没有可读表情、羽片层次和动作意图。角色必须有实际网格、材质、骨骼和动画交付；AI概念图只作为设定。
5. **五声音阶不是历史配乐证明。** 文物提供金石音色依据，音乐的调式、旋律、织体仍是当代创作；对白需要固定两种声线，不能任由设备挑选同一TTS。
6. **第一次绘制也是作品。** 根因已通过隔离实验确认：CSS依赖JS才加载。首份HTML必须独立承载完整暗色开场，资产状态与可玩就绪分开。

## 指定网站的实际研究边界

### Showreel.design

来源：https://showreel.design/ 。网页工具403，联网浏览器已成功打开首页，保存 `site-captures/showreel.png` 和 `.txt`。可见Art Graft Reel2026、Aixsponza Design Reel等作品及3D/CGI、UI/UX Motion分类。没有声称逐镜看完这些视频。它用于建立材质特写、角色动作、节奏剪辑的参照，不意味着获得视频或模型授权。具体候选见资产登记。

### Sael — Farewell Light

来源：https://sael.net/demo/farewell-light/ 。实际进入首页并启动新游戏，观察到实时海岸、远方灯塔、暖灯与冷色晶体构成的前中远景；菜单角色与进入后的世界共用视觉语言。启动后出现宽银幕建立镜头和署名角色的字幕，保存 `sael-started.png` 与 `sael-forward.png`。后一个文件名只是操作记录，画面仍处开场序列，**不据此宣称已经验证自由移动或完整通关**；没有录音测评。

设计推论：金沙首页使用角色近景与第一处未知入口；进入后短暂推镜把控制交还玩家。光源应有叙事角色，前景引导目光，不能把灯塔/晶体/服装当金沙素材照抄。控制提示可短暂出现后收起。

### Sael — Plane of Focus / River Bend / Set the Mood

官方说明已读，未完成交互实测：
- https://sael.net/plane-of-focus/ ：镜头焦点与光圈可操作。用于文物检视时的有目的对焦；自由移动时不要持续重景深。
- https://sael.net/river-bend/ ：通过操控水流/沉积理解河道。启发金沙的文化内容要在动作中被理解；不要把该模型变成真实古河道复原。
- https://sael.net/interior/ ：材料与日光可操作。启发把金、玉、土、羽放到同一盏灯下验证，而非分别做漂亮样图。

### MotionSites

来源：https://motionsites.ai/ 。实际打开并记录首页，看到Flower Valley、Golden Portal、Ink Reveal、Particle Self、Card Story等卡片。部分缩略图仍为加载占位，卡片未暴露稳定anchor详情URL；没有宣称看完其动画。它的优势是界面动效与构成候选，不把首页滚动模板等同于游戏关卡。商业prompt、开源代码与媒体的许可分别核对。

## 补充参照的作用

- [Journey官方](https://thatgamecompany.com/journey/)：以远方目标、旅行与声音建立情绪；不复刻其服装、符号或音乐，也不把桌面主机画质直接当Web性能承诺。
- [Lusion Of The Oak](https://lusion.co/projects/of_the_oak/)：古木结构与压缩管线共同设计；只参考方法。
- [Codrops ZERO](https://tympanus.net/codrops/2026/07/17/zero-the-engineering-behind-a-defiant-interactive-narrative/)：分段生命周期与空间转场；不是把玩家输入绑成滚动影片。
- [Poly Haven](https://polyhaven.com/license)、[ambientCG](https://docs.ambientcg.com/license/)：明确授权的自然材质候选，需再加工统一尺度、色彩和运行成本。

## 参考→决策→检验

| 观察/证据 | 我们的设计决定 | 如何检验 |
|---|---|---|
| 首屏裸露HTML | 内联关键CSS、原生hidden、静态角色轮廓、阶段提示 | 冷缓存/延迟JS/失败录屏，逐帧无白色裸页 |
| V1全景把下一站全部曝光 | S弯＋局部分叉＋视线遮挡 | 起点自由转镜看不到后两庭院与终局 |
| 参考里穿门与前景掠过形成动势 | 角色尺度小、根洞压低镜头、河湾打开空间 | 不夺走控制，不穿模，无近处生成整片景物 |
| 角色在文化之外显得通用 | 铜鸟轮廓依据＋金箔边缘工艺＋原创性格和光核 | 黑色剪影可认；关闭Bloom仍可读表情和羽毛 |
| 文物卡只是阅读 | 每件核心文物对应不同观察动作 | 玩家可以用自己的话说出一个真实造型/工艺事实 |
| 原音色单薄且同声线 | 原创音乐分轨＋两固定声线＋字幕事件队列 | 不抢话、不叠对白，音乐避让，跨设备音色一致 |

## 概念图校读

`jinsha-art-direction-v2.png` 由内置imagegen生成，提示词见 `concept-prompt.txt`。这是美术目标示意，不是已实现的游戏画面、三维模型或历史复原。

优点：羽层、眼神、暖色局部光核、近景树根遮挡与河湾揭示，方向对题。进入建模前需精修：减少肩部“铠甲”感；冠羽更贴合原创羽灵轮廓，避免落入通用仙侠神兽；自然羽毛不得全部做高开销透明卡；金饰图案必须另据官方资料制作，概念图的图案不用于考古说明。生成画面的高频表面/水面效果不能承诺一比一实时实现，应以单章实机样片校准。
