# 金沙探索游戏 v2：参考作品与资产登记

核查日期：2026-11-18。本文只进行调研和设计推论，没有购买订阅、登录付费内容、下载受限资产或把第三方媒体装入游戏。

## 1. 先区分三种“资源”

- **参考作品**：学习构图、镜头、节奏和交互。能播放并不代表能复制模型、配乐或代码。
- **制作资料**：教程、开源实现、角色制作过程。借鉴方法；依各自许可证决定是否使用代码。
- **可用资产**：明确可下载、许可证允许集成的模型、贴图与环境光。入库时登记作者、版本、文件、许可与改造记录。

本轮精选以下九项。Sael 的 Farewell Light / The Plane of Focus / River Bend 由主调研另行分析，不重复堆砌。

## 2. 精选九项及具体使用判断

### R01 · Showreel.design — Aixsponza Design Reel

- 具体页：[Aixsponza Design Reel](https://showreel.design/videos/aixsponza-aixsponza-design-reel/)，入口：[3D / CGI 分类](https://showreel.design/category/3d-cgi/)。
- **证据**：官方索引标为 3D/CGI、Minimal/Clean、Electronic/Synth，导向创作者 Aixsponza。主调研已在真实页面取得首页与卡片文字；本子任务的网页抓取返回 403，因此仅核验官方索引，未逐镜观看该 Reel。
- **设计推论**：用它建立“工艺细节—整体角色—动作”的三层观看顺序。金沙首页可以先展示一片带锤揲痕迹的金羽，再露出精灵面容，最后展示其飞行动作；用一个视觉母题贯穿，不叠满粒子。
- **许可/成本**：[官方 About](https://showreel.design/about/)明确视频版权归原创作者。它是灵感策展，不是可下载游戏资产库；原视频、音乐不入库。学习成本低，重新制作同等镜头与模型的成本高。离线影片的复杂镜头不能直接当作实时网页预算。

### R02 · MotionSites — Flower Valley / Golden Portal / Ink Reveal

- 页面：[首页](https://motionsites.ai/)、[3D 分类](https://motionsites.ai/3d-websites)、[动态背景](https://motionsites.ai/backgrounds)。已观察的卡片名保存在 [motionsites.txt](site-captures/motionsites.txt)；尚未核实各卡片稳定直达 URL。
- **证据**：官网提供设计提示词、模板、动态背景；卡片可见 Flower Valley、Golden Portal、Particle Self、Ink Reveal、Card Story。首页存在会员入口；卡片名与类别不等于已经验证动画效果或获得素材权利。
- **设计推论**：分别作为林间纵深、门槛转场、角色凝聚、局部揭示与角色档案切换的候选。金沙应采用“金羽显影”而非照搬墨迹；用于角色卡和章节交接，不能把滚动展示直接当成角色探索。
- **许可/成本**：[官方条款](https://motionsites.ai/terms)允许将已获权限的提示词和源码用于自有项目，禁止再分发原始库。官方另有[免费仓库](https://github.com/Motionsites-AI/claude-skill)：[许可](https://raw.githubusercontent.com/Motionsites-AI/claude-skill/main/LICENSE)把代码/参考说明的 MIT 与 examples/media 的版权分开，后者允许用该 skill 建站，不能作为媒体集合转售或再分发。当前不把这些视频用于游戏，先采用原创动效。网页案例对前台可行，现成电影视频不支持玩家自由转向。

### R03 · Codrops — ZERO 的分段叙事工程

- 创作者技术说明：[ZERO: The Engineering Behind a Defiant Interactive Narrative](https://tympanus.net/codrops/2026/07/17/zero-the-engineering-behind-a-defiant-interactive-narrative/)。
- **证据**：作者描述从画圆入口开始，穿越不同叙事阶段，经过隧道再出现云上城市；每段拥有 enter、scrub、update、teardown 生命周期。本文读到作者技术文章的索引全文片段，未把营销性能数字当作本项目实测。
- **设计推论**：这是“前方逐步显现”的最直接工程参考。金沙改成当前位置、下一空间预载、远端休眠三层；转弯、树根门与峡隙提供遮蔽，进入门槛时再释放下一景。借鉴分段生命周期，输入仍由玩家行走/飞行决定，不改成滚轮轨道影片。
- **许可/成本**：文章可阅读，原项目媒体与实现许可未核验，不复制源码。架构实现成本中等，场景生产与遮挡测试成本高；Web 可行，但须实测相邻段重叠时的内存与帧耗。先做一个真正连贯的精品章节，优于一下铺开多个未打磨场景。

### R04 · Lusion — Of The Oak

- [官方案例](https://lusion.co/projects/of_the_oak/)，[体验入口](https://oftheoak.co.uk/)。
- **证据**：Lusion 为 MLF 与 Kew 的装置制作网页延伸；官方描述 Houdini 到 WebGL 的树、枝、节点管线，以定制格式和实例化将相关下载压到 3.5 MB。这是该项目自报数据，不是全站/金沙的预算承诺。
- **设计推论**：乌木不是背景装饰，而是有内部结构的记忆载体：玩家停驻时，微光沿根须流动，先看见树的生命纹路，再找到藏在根部的通路。学习“数据结构与艺术形式一起设计”，而不是给现成树林再加灯带。
- **许可/成本**：未发现开放模型或源码许可，仅作参考；Houdini管线需专门技术美术，不能假设复制现成。金沙首章可用 Blender 制作关键古木、烘焙凹凸/阴影、枝叶实例化达到适合 Web 的版本，不将 Houdini 设为首章硬依赖。

### R05 · Bruno Simon — 可操作世界与恢复设计

- [官方体验](https://bruno-simon.com/)，[官方源码与 Blender 管线](https://github.com/brunosimon/folio-2025)。
- **证据**：站点明确提供驾驶探索、隐藏发现、交互、脱困、画质与多输入设备；仓库分出 Player、View、Zones、Foliage、Fog、Audio，并说明 GLB/纹理压缩流程。
- **设计推论**：借鉴角色有重量的起停、触发区、脱困与输入接管；保留玩家每一步的主动性。不要复制它的俯瞰大地图布局，金沙依然要遮蔽后续空间。引路只给方向与声音，不直接把玩家送到答案。
- **许可/成本**：站点与仓库公开说明代码为 MIT；复用需保留许可，并核查具体文件是否含单独声明。配乐虽被作者另标 CC0，但其风格不是古蜀配乐，故不建议照搬。代码学习免费，适配与动作打磨成本中等；是已公开运行的 Web 实现，目标设备性能仍须另测。

### R06 · Poly Haven — 苔石、蕨类与林地环境光

- [Rock Moss Set 02](https://polyhaven.com/a/rock_moss_set_02)：Kless Gyzen，官网标 58K triangles；[Fern 02](https://polyhaven.com/a/fern_02)：Rico Cilliers / Rob Tuytel，官网标 6K triangles；[Forest Slope HDRI](https://polyhaven.com/a/forest_slope)：Andreas Mischok。
- **证据**：有可下载模型及 PBR 贴图，石组有缝隙/苔藓，蕨丛具有不一致轮廓，HDRI 提供林间柔光。这些是自然资产，不是金沙本地物种或考古环境证据。
- **设计推论**：用于近景湿石、地表和转角前景，把程序球块替换成具有真实表面尺度的材料；英雄古木、角色与文物仍原创。HDRI 用于一致反射，不把完整松林背景照搬成成都史前植被。
- **许可/成本**：[资产 CC0](https://polyhaven.com/license)；免费，可改造入游戏。注意官方许可把网站文案、标志、示例渲染等与资产区别对待。Web 可行但需预处理：只下载所需分辨率、减面/LOD、合并通道、KTX2压缩、实例化；不能每块石头直接复制一份58K高模及8K贴图。实际体积与适配成本在样片导入后记录，不凭网页包大小推算最终性能。

### R07 · ambientCG — Ground015 地面材料

- [Ground 015](https://ambientcg.com/view?id=Ground015)，[明确资产许可](https://docs.ambientcg.com/license/)。
- **证据**：泥土、森林地面、枝条主题的 PBR 材料，制作方法标为 Approximation；1K JPG 包约10MB只是源包选择，不能称其为摄影扫描或最终游戏体积。
- **设计推论**：用于泥岸与树根通道的底材；加入顶点颜色/另一湿土材质破除平铺，再用模型控制局部树根和脚下落叶。通道弯曲、地面高差、痕迹本身应引导玩家，不依赖满屏箭头。
- **许可/成本**：CC0允许将原资产集成游戏，免费且适配成本低至中。Web 采用1K/2K材质和有限混合层，避免全场景高分辨率位移。不同粗糙度与湿度要服务同一套灯光，不能下载完简单堆叠。

### R08 · Blender Studio — Sprite Fright 的角色制作过程

- [项目 About / License](https://studio.blender.org/projects/sprite-fright/pages/about/)，[Sprite 制作页面](https://studio.blender.org/projects/sprite-fright/sprite/)，[制作周会说明](https://studio.blender.org/blog/sprite-fright-weeklies-recordings/)。
- **证据**：官方公开索引列出雕刻、重拓扑、着色与表情测试；部分具体制作内容标需订阅，本轮没有访问。官方 About 的搜索索引说明项目内容采用 CC BY 1.0（标志、商标与另行标明材料除外），直读 About 曾返回402，下载时须再次核对具体条目。
- **设计推论**：学习“轮廓—表情—动作”的角色生产流程，先出正侧背设定和表情表，再做雕刻与游戏拓扑。金沙角色不能直接把蘑菇小人换材质；来源、体态、羽片、动作、性格都要有独立依据。
- **许可/成本**：此处主要作为制作学习资料；购买资料访问与资产使用许可是两件事。高质量角色成本高，网页交付需从渲染级角色重拓扑、烘焙、限制骨骼/表情数量。不要用“几颗球+发光”冒充精雕完成，也不要把影院资产直接丢进浏览器。

### R09 · Three.js 官方示例 — 角色动画与真实空间碰撞

- [Skinning and morphing](https://threejs.org/examples/webgl_animation_skinning_morph.html)：动作状态、一次性动作过渡与独立表情；[Octree 静态网格碰撞](https://threejs.org/examples/games_fps.html)；[体积光示例](https://threejs.org/examples/webgpu_volume_lighting.html)。
- **设计推论**：将精灵待机/前进/刹停/探头/受惊/触碰做成动画状态；嘴与眼睛的表情独立于身体。角色不得穿过树根、石壁；镜头另做障碍检测。体积光只在少数关键镜头使用，低档保留雾与光束替代。
- **许可/成本**：[Three.js 代码MIT](https://raw.githubusercontent.com/mrdoob/three.js/dev/LICENSE)，具体模型仍按单独许可核验；角色动画例中的模型页面标CC0。源码学习成本低，原创动作制作与整合成本中高。WebGPU效果需要能力检测与降级，不把该示例列为全部浏览器必备。

## 3. 真正要落实的制作选择（原创设计推论）

1. **加载也属于游戏第一镜。** HTML 内联背景与必要样式先出现，给真实进度或阶段状态；相同色彩的角色剪影/金羽微光无缝交接实时场景。下一段后台加载，失败时仍保留可操作的已加载空间与重试，不能先白页再造假百分比。
2. **隐藏要靠空间，而非突然生成。** 一段只能看见当前主要地标与下一段的局部信号；以弯道、林下、根洞、水汽形成遮挡。贴脸出现的整座山是穿帮，远端预载应早于玩家可视门槛。
3. **一条主线，局部分叉。** 先听见/看见一点线索，玩家自行接近；支路提供角色互动和细节记忆，重新汇入前进路径。停止时也有风、呼吸、眨眼与短对白，但不持续播讲。
4. **高级感来自少量精制焦点。** 首章只选一位角色、一棵古木、一段泥岸、一件主文物做到镜头近看成立。环境通用材料可用CC0，角色与文化符号的识别性必须原创。
5. **动画有因果。** 金羽感应未知方向，角色探头后才进入新空间，光只暴露被触碰的纹样。这样动效就是发现行为的一部分，而不是网站式装饰。

## 4. 入库与制作优先级

| 优先级 | 项目 | 本轮状态 | 下一步验证 |
|---|---|---|---|
| P0 | 原创精灵设定、轮廓与动作表 | 待主方案确定 | 同一材质在近景/背影/逆光下都能认出；角色卡有明确身份与来源 |
| P0 | 一段弯曲林道到首次豁然开朗 | 架构参考已明确 | 不提前泄露下一场景；转身可回看；无穿模与边界断裂 |
| P0 | 冷启动外壳与分段加载 | 方法已明确 | 冷缓存/慢网录屏；HTML起至WebGL首帧没有白屏 |
| P1 | 苔石、蕨类、地面材料 | CC0来源已核验，尚未下载集成 | 先导入一组做纹理/法线/色彩一致性和显存测试 |
| P1 | 角色口型/眼神与对白触发 | 官方动画模式可借鉴 | 正在移动/重复进入时不抢话；字幕与声音一致 |
| P2 | 复杂体积光、远景高精模型 | 仅候选 | 必须在目标设备余量充足后加入，不作为掩饰低质量模型的滤镜 |

## 5. 验证边界与沉淀

网页证据包括官方正文、官方项目/仓库说明、官方搜索索引，以及主调研提供的真实首屏文字/截图。没有把未加载的视频缩略图、商品卡片标题或制作者自报性能，当成已亲自试玩或已获得素材授权。Showreel抓取403、Blender部分402都已保留记录；网页库存、许可和价格会变化，真正下载入库前重核具体版本。

本项目应沉淀的不是“网站大全”，而是四张工作表：**镜头节奏表、资产出处与处理表、角色动作/声线表、实机帧耗与加载表**。只有这些进入制作与验收，参考网站才真正变成产品质量。
