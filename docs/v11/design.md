# 金沙：古蜀秘境

## 故事从一个能实测的问题开始

木柱早已朽去。站在原来的柱洞旁，今天的人还能知道先民看到的天空吗？玩家以羽灵烁羽的视角，从古河岸走到九柱基址。三个段落依次追问水怎样改变环境、人怎样改变材料、现场位置怎样帮助我们理解遗物。最后一段将玩家亲手量出的轴向带进冬至日出的演出，随后回到当代展陈。

第十八号遗迹保留柱洞，馆方列出过不同的建筑解释。研究团队比较过东偏南 27.17° 的轴向和东偏南 27.46° 的冬至日出方位。本作据此创作候日情节。木架、羽灵、跨时代作坊、可取回的标本和数字展柜属于演绎。[金沙遗迹馆](https://www.jinshasitemuseum.com/node/216) · [九柱基址的研究说明](https://www.nopss.gov.cn/n/2015/0727/c358567-27367530.html)

## 九处现场

| 地点 | 玩家亲手做的事 | 下一处为何值得去 |
|---|---|---|
| 河床探方 | 拂去覆土，在两端定位同一层界，湿筛样土并辨认陶片口沿。放大镜可在东西取样窗对照四个深度的粒径、根隙和界面 | 一条砂带引出它原本所属的河流 |
| 古河湾 | 掌竹排寻找缓流测点，观察与拦取漂木；可单独挑战回涡 | 游离木段可能来自上游，要找到扎在岸上的树根 |
| 古木鉴定台 | 分辨原位侧根和冲来的木段，将木材切片与显微参照配准 | 看过木头内部，再去读工匠在硬玉上留下的痕迹 |
| 滨岸治玉作坊 | 用素绳试拉、给绳蘸砂、补水往复锯切 | 玉口规能找到陶器缺失的口沿 |
| 陶作修复架 | 定径、旋转碎片，将三个实际断面合拢 | 修好的陶托送往铜鸟支护台 |
| 铜鸟支护台 | 调胸腹两托，缓降模型，看薄尾是否受力 | 可移动的复制件和不能随便搬动的象牙，要求不同的观察方法 |
| 象牙埋藏区 | 对叠压、断口、泥层分别取景，保存三张自己拍下的照片 | 侧光帮助辨认断面，也提出极薄金片应如何观察 |
| 金箔光学工位 | 使用反射和透射光，区分镂孔、折痕和破损 | 金片留白和建筑空印都会保存形状 |
| 九柱基址 | 在三行三列的柱洞间拉测绳，比较斜距、开间和进深 | 把测得的朝向带到黎明的地平线 |

木材鉴定、象牙保护和金饰工艺的背景可以在现场之外继续核对。游戏里的微观切片、支托和光学试片为教学模型。[馆方秋枫研究](https://www.jinshasitemuseum.com/seardetail/2191) · [滨河祭祀区](https://www.jinshasitemuseum.com/seardetail/699) · [太阳神鸟金饰](https://www.jinshasitemuseum.com/seardetail/681)

## 地图、珍藏与羽装

按 J 打开地图，展开「地图支线」可标记西岸织棚、东台石场或北汊渔地。玩家也可自行走近。主线每次首获 30 阅历，可选现场鉴定首次答对再获 18，野外三件拾遗各有 12。阅历总量解锁羽装，余额用于把一套羽装强化至二阶或三阶，花过的阅历仍计入解锁进度。已鉴定的题目、已收录的标本和已购买的强化均保存在本机。

芦行、巡空、闪身对应不同的身体特征与运动参数。在标题的「烁羽 · 羽装」内可试阅，旅途内从地图进入可装备。「观察烁羽」打开当前羽装的骨骼模型，玩家可以主动转动视角，从正面看羽冠，或从侧面比较地面与飞行姿态。每件珍藏标出考古依据、游戏演绎和来源。支持三维审看的器物有独立转台。

通关后进入金面具特展。把开场只见到正面的金面具转过来，可观察薄片的内壁以及眼、口的剪切边缘。游戏将馆方描述的捶揲、剪切与表面差异变成可调侧光的三维教学展品。[金沙遗址博物馆 · 商周大金面具](https://www.jinshasitemuseum.com/node/197)

## 实际比对与参考

《待寄出的春信》把花笺叠影、描星、编排三声部、写信与送信连起来。金沙旧版的来信、终章题记和三声部留下了相似的游玩印象。新版从首页到结局沿着器物、材料、埋藏位置与柱洞方向推进。两作仍共有第三人称移动、飞行、交互键等常见操作。

原参考视频长约 110.47 秒。复核前轮按 30 fps 采样的 3,314 个画面指标与四页关键帧，约 25 秒羽灵从甬道飞出，约 66–68 秒穿过日轮后才看见下一段建筑。本作保留背后跟拍与局部揭示的节奏，用可行走的滨河地形、材料操作与未知现场承接这两个转场。[帧索引](../video/keyframe-index.json)

本轮在侧栏核对了 12 个游戏案例以及三个视觉资源页面。下列对应关系是金沙的设计取舍。
