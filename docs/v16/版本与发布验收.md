# 金沙：古蜀秘境 · 游戏与发布验收

## 从哪里开始玩

点击右上角「全屏体验」可在首页、河岸或工作台进入全屏。游戏内回顾章节时也可以切换显示，退出后继续原来的调查。手机窄屏工作台使用四角展开图标。解压试玩包的独立 HTTP 验收包含实际进入与退出全屏。

打开[本机游戏](http://127.0.0.1:5188/)，或双击项目里的「启动游戏.cmd」。第一次进入时，从序章落到滨河探方边。有旅程记录时，首页可以继续探索，也可以「另启新旅程」。要重做已经归档的一站，在河岸或工作台按 L 打开「回顾章节」，退出后可接着做原来的事。

建议先试着向第一段芦湾走近，观察水鸟何时抬头、转身和离水。按 P 拖动镜头，可以把眼前这一刻拍下来。打开 J 键图鉴，选「证据推理台」，第一份剖面案卷从新档就能玩。触屏可从河岸菜单进入相同的图鉴、摄影和推理入口。

## 九站之后还能做什么

九站从陶片口沿、古河道与古根，一路串到湿砂锯玉、拼陶、铜鸟支护、象牙摄影、金箔光检与九柱定向。新加的四份案卷按新旅程、第二站、第五站、第九站的进度开放。每卷有三份观察对象，比较其中两份就能提出判断。例如，把剖面上的浅土与夹砾带并置，可以标记一处值得复查的层界；换上下两处土样，就能讨论为什么应当分开编号。每条研判还说明这组观察能回答到哪里。

手册会保存每卷的摘录和研判。收集十二条研判有自己的进度，重做组合不会重复发放主线阅历。河岸摄影的 JPG 直接由当前三维场景输出，不带游戏界面，可输出 1440 × 1920、1080 × 1920 或 1920 × 1080。

## 案例怎样影响设计

- 《Heaven’s Vault》把解释与调查绑在一起；《Return of the Obra Dinn》要求玩家从可回看的现场形成判断。金沙采用了比较观察、换证重试和保留判断依据的结构，把问题落在不同土层、河湾颗粒、工艺痕迹和柱洞位置上。[inkle](https://www.inklestudios.com/heavensvault/) · [Return of the Obra Dinn](https://obradinn.com/)
- 《A Short Hike》的自由移动给路途中偶遇的小事留下空间。金沙第一处芦汊的水鸟随玩家的接近与移动状态反应；玩家既可以追随，也可以停步构图。[A Short Hike](https://ashorthike.com/)
- 金沙遗址博物馆的遗迹与研究资料是器物、环境和田野动作的依据。游戏另行设计了烁羽、可走地图、教学复制件、观察图版以及九柱上部的教学复原。完整历史和美术出处可在游戏首页查看。[遗迹馆](https://www.jinshasitemuseum.com/node/216) · [植物考古](https://www.jinshasitemuseum.com/info/4877) · [游戏素材署名](../../public/credits-v10.html)

[可检索的完整参考网站 HTML](../../public/references.html) 收录 187 个独立地址。在「研究轮次」选择「本次复访 · V16」，可找回本轮侧边栏的 14 个页面，其中包括 Farewell Light、Showreel、MotionSites 和金沙遗址博物馆。

## 小红书发布材料

[作品放映页](发布物料/作品放映页.html) 可以在解压整份发布包后离线打开。[发布文案](发布物料/发布文案.txt) 内有视频首发和图文手记两套可直接编辑的正文、标签与置顶评论。首发采用真实铜鸟操作封面，图文版可把同一器物的概念图与实际工作台相邻排放，让读者看到从美术设想到玩家动作的差异。

十个视频镜头全部取自浏览器内操作，包含古蜀题材创作场景与教学复原。声轨以游戏内采集的河岸音乐、环境声及项目的两种角色配音重新剪混。两幅独立概念图采用 AI 辅助生成，实机封面、实机图文配图均有文字标记。

[小红书发布包](金沙古蜀秘境-小红书发布包.zip) 共九份文件，解压后打开「作品放映页.html」即可浏览。[网页试玩包](金沙古蜀秘境-网页试玩包.zip) 可以单独发给合作方。完整解压后，Windows 可在装有 Node.js 或 Python 的电脑上双击「启动试玩.cmd」，也可将 site 目录的内容部署到静态网站根目录，让访客直接用浏览器游玩。
