# 金沙：古蜀秘境 · 从第一份记录到终章展签

## 玩家带走什么

烁羽从古河岸起飞时，玩家面对一个可以自己验证的问题。九处木柱已经消失，泥土里还剩下什么证据，足以让人讨论这座建筑的朝向？主线让玩家练习三件事：从土地里取证，读懂材料上的手艺，保存遗物之间的位置关系。走到冬至日出后，玩家以今天的观察者身份为另一位观众选证、显影、制签。

## 旅程、回顾和去现场

| 玩家想做的事 | 入口 | 实际结果 |
| --- | --- | --- |
| 第一次游玩 | 首页「开始探索」 | 读序章、选看线索，再落到探方边。 |
| 换一个全新的起点 | 已有记录时，首页「另启新旅程」 | 创建独立的一卷，从序章和零归档开始。声音、画质沿用玩家偏好。 |
| 回到旧进度 | 首页「旅程档案」 | 每卷列出地点和归档数，选中后进入该卷。 |
| 重做有印象的一项调查 | 游玩中的「回顾章节」或地图「就地回顾」 | 暂停当前探索、打开已完成工位。退出后回到离开的现场。 |
| 自己飞去找遗迹 | 在图鉴的河岸图上点选地点，再选「在罗盘标记」 | 变更目的地，起点仍是烁羽的当前位置。可自行跋涉或用循迹领航。 |

## 九站脚本与证据传递

| 现场 | 玩家亲手完成的动作 | 下一步为什么值得去 |
| --- | --- | --- |
| 滨河探方 | 刷开两处窗口、定位砂泥界面、湿筛取样、旋看口沿 | 砂层引出旧河的流向。 |
| 古河道渡口 | 驾竹排穿过回湾，用漂木和测线观察水流 | 水能搬运木料，岸上的原位根盘则保存另一类证据。 |
| 古木鉴定台 | 翻看切片、比对纹理、观看树冠复原 | 从木材组织的差异，过渡到工匠怎样利用材料。 |
| 滨岸治玉作坊 | 给绳索加水加砂、往复锯切、检查切面 | 把工位上的口规带到散落的陶片前。 |
| 陶作修复架 | 定径、选片、旋转对缝 | 修复器物之后，还要考虑怎样支护。 |
| 铜鸟支护台 | 察看薄尾、调整两处支点、缓慢落托 | 搬动器物会改变现场，下一站先记录再判断。 |
| 滨河象牙埋藏区 | 拖动比例尺、取景对焦、保存三种原位关系 | 从断口和叠压关系转入对金箔边缘的观察。 |
| 金箔光学工位 | 侧转试片、移动提灯、比较反射与透射细节 | 四鸟和十二道芒带出最后的方向问题。 |
| 滨河建筑基址 | 给相邻柱洞架测绳，量开间、进深与轴向 | 拿自己的基线候日，比较轴向与东南地平线。 |

冬至以后，三排底片分别对应沿河踏查、工艺与祭祀区调查。每排从三个现场中选一件，再推压辊显影，共有 27 种组合。选择象牙现场会使用该卷有效的实拍底片。三个声部随选片组合，结束后展签留在这份旅程的手册里。

## 西台烟火里

西岸新增一段可进入的缓台和木骨泥墙小院。玩家在灰坑旁环洗土样、用网勺取出浮物，再放大比较炭粒和木屑。第一次完成会登记「炭化稻粒图记」，可以回到现场再操作。考古依据来自黄忠小学地点的植物考古资料以及金沙居址介绍。游戏中的西台位置、房屋外观和浮选台为教学场景，加载画面使用为本作生成的河岸居址概念图。[黄忠小学地点植物考古](https://www.jinshasitemuseum.com/info/4877) · [金沙遗址与古河道](https://www.jinshasitemuseum.com/info/706)

大型树根的秋枫鉴定有实物研究依据。九柱建筑的方向与冬至日出是已有研究提出的比较，日出镜头、烁羽和当代印相台属于创作。[秋枫鉴定](https://www.jinshasitemuseum.com/seardetail/2191) · [九柱方位研究](https://www.nopss.gov.cn/n/2015/0727/c358567-27367530.html)

## 十三个游戏案例怎样用于这次验收

以下是根据官方介绍提取的设计问题，以及在金沙现场检查它的方法。表中同时列出本轮新增设计和需要继续成立的既有关卡体验。

| 案例与观察 | 在金沙检查什么 |
| --- | --- |
| 《Journey》让远处的山为长途旅行定向。[开发者](https://thatgamecompany.com/journey/) | 序章即提出九柱问题，日出回应最初的视线。 |
| 《Heaven’s Vault》让玩家通过遗迹和铭文逐步形成理解。[开发者](https://www.inklestudios.com/heavensvault/) | 先看到取样位置，再决定这块陶片能说明什么。 |
| 《Outer Wilds》用具体疑问驱动寻找地点，用工具读取环境。[开发者](https://www.mobiusdigitalgames.com/outer-wilds.html) | 可以在地图选择目标、自行接近，现场工作由玩家完成。 |
| 《Return of the Obra Dinn》要求调查者从现场重建事件。[开发者](https://obradinn.com/) | 玩家自己的象牙原位照片可再次作为终章证据。 |
| 《Chants of Sennaar》把观察、比较和推断做成解谜动作。[开发者](https://www.rundisc.io/chants-of-sennaar/) | 比较炭粒与杂物、反光与透光，反馈指出应观察的差异。 |
| 《Gorogoa》通过移动、组合画面来建立关系。[发行商](https://annapurnainteractive.com/zh-cn/games/gorogoa) | 终章让玩家选择三幅证据并排成自己的展签。 |
| 《ABZÛ》围绕潜游与水下环境组织探索体验。[发行商](https://505games.com/games/abzu/) | 由河面、回流、渔标与水下遗物组织河段体验。 |
| 《The Room Three》让玩家在不同尺度上检查可操作物件。[开发者](https://www.fireproofgames.com/games/the-room-three-2) | 从整个灰坑缩小到浮选桶，最后转看单颗标本的纵沟。 |
| 《Jusant》把工具、体力和攀爬路线结合起来。[开发者](https://dont-nod.com/en/games/jusant/) | 飞行、停栖、绕行各有适用场景，选地点后仍需抵达。 |
| 《A Short Hike》把步行、攀登与滑翔放在一片可探索地形中。[开发者](https://ashorthike.com/) | 西台接在原河岸上，玩家可以偏离主线再回来。 |
| 《A Highland Song》用路径选择、地形和音乐组织山地旅程。[开发者](https://www.inklestudios.com/a-highland-song/) | 用实际地表采样绘等高线，让高地和河湾在手册里有形状。 |
| 《Alba》团队介绍了便于单手游玩的构图和环境设计。[开发者美术手记](https://ustwogames.co.uk/news/the-environment-art-of-alba-a-wildlife-adventure/) | 小屏单独检查选档按钮、探查工具、退出与证物观看的空间。 |
| 《Monument Valley》系列通过视角让人重新理解空间关系。[开发者](https://www.monumentvalleygame.com/) | 转看遗物和对齐轴向时，被改变的关系应当直接可见。 |

动效参照包括 Showreel 的镜头节奏、Farewell Light 的明暗过渡和 MotionSites 的交互呈现。落实在旅程卷册的薄金边、河湾晨光加载画面与终章显影的节奏中。场景图、工位模型、地图和交互均在本作内制作。[Showreel](https://showreel.design/) · [Farewell Light](https://sael.net/demo/farewell-light/) · [MotionSites](https://motionsites.ai/)
