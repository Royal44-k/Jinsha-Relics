# 《金沙：古蜀秘境》游玩与验收

## 从哪里继续

| 你想做什么 | 游戏入口 | 进入后会发生什么 |
| --- | --- | --- |
| 第一次认识金沙 | 首页「开始探索」 | 在序章翻看现场线索，选择「落到探方边」后开始第一站。 |
| 从头走一遍 | 已有进度的首页「另启新旅程」 | 新卷从零归档开始。原卷的阅历、底片、羽装和已完成的调查仍保存在这台设备的同一浏览器中。 |
| 回到某次调查 | 首页「旅程档案」 | 按归档数和地点挑选旧卷。「继续探索」可以直接进入当前卷。 |
| 重玩某一关 | 游戏内「回顾章节」或 L 键 | 暂停手上的调查，选已归档的工位，退出后接着刚才的操作。 |
| 去新的野外地点 | 游戏内「探险图鉴」或 J 键 | 在地图选点、读线索、标记罗盘，再自行飞行或跟随领航。 |

## 实际复核

- **从序章走到终章。** 新的浏览器档案从滨河探方出发，在九个工位实际操作，完成冬至候日与三联展签。沿途实拍的三张象牙底片保存在手册里；结束后能打开金面具特展、重看自己的展签并返回河岸。[九站实走记录](final-campaign/playthrough.json) · [终章画面](final-campaign/solstice.jpg)
- **查旧档和重入。** 给测试浏览器准备一份四站旧档，再用首页新开一卷，切回原卷继续第五站。另有用例在工作台提交后立即离开、模拟存储写入失败再重试，检查已完成的工作归入正确的旅程。[多旅程记录](journeys/journeys.json) · [章节回顾记录](review/chapter-review-report.json)
- **走另一条路。** 从河岸标记西台，实飞到灰坑。中途取消可以再次取样，认错标本可以转回去比较；首次辨认炭化稻粒得到 12 点阅历。桌面使用键鼠，触屏使用 390×844 浏览器触摸仿真。[桌面记录](west-yard.json) · [触屏记录](yard-touch/west-yard.json) · [西台实景](west-yard-arrival.jpg)
- **听环境变化。** 接近小院时，河声渐退，出现穗叶擦动和陶器轻碰。进入浮选操作可听见湿筛和桶水；旁白响起时环境音自动降低。音频检查读取浏览器实际音轨的输出、静音和重复进出时的声道数。[环境声记录](west-court-audio.json)
- **在地图上作决定。** 用地图选择治玉工位就地回顾，返回后保留选点与滚动位置。把罗盘改指西台后，烁羽仍站在原处。1280×800、390×844、667×375 三种尺寸中，支线说明和导航均可独立阅读和操作。[地图验收](river-atlas.json) · [触屏地图画面](river-atlas-portrait.jpg)

## 画面与设备范围

本机 Edge 使用 AMD Radeon 的 WebGL，按 1040×650 桌面窗口单独跑完整条主线。九个工位各自的帧间隔第 95 百分位落在 16.8 至 17.1 毫秒之间。探方仍记录到一次约 284 毫秒的停顿，象牙工位约 234 毫秒。数据包含自动鼠标操作与截图；不同显卡和真实手机的表现仍待独立测量。[每站帧时明细](final-campaign/playthrough.json)

考古资料、建筑复原边界、九站之间的线索及十三个参考案例见[策划与参考](策划与参考.md)。
