# V7 环境精修 · 方案与依据

制作方向：从「管状树门、均匀树列、同样的草地」转为有生长逻辑的林冠、不同视距与有方向的微气候。保留连续地形、既有路径与五境机关，不新增需要玩家学习的边界。

## 改动顺序

1. 根穹由两条完整圆弧改为两株不对称古木与断枝的负形开口；板根接地、主干有收束与纵向棱脊，碰撞跟随同一条曲线生成。
2. 三种背景树以不同冠层、分叉、簇状叶团和树干摆幅形成节奏，避免每株都是相同圆伞。
3. 近地材质补入宏观色差、湿润斑块与细法线，保持脚底采样与地面一致。
4. 林地低雾、湿地掠水气流、岩廊落尘、聚落缓升窑烟、暮湾水平雾层以少量绘制表现，不称真实体积流体；低画质降低数量，减动态静止。
5. 以固定机位比较五境与根穹近景；检查着色错误、中央净空、碰撞与绘制成本。最终整机测试由主agent统一执行。

## 实施发现与修正

- 起初只读forest发现距主路8m外没有直接树代理；继续追踪traversal后确认那里已自动补齐树干圆柱。因此准确的问题是旧代理不随弯曲树干移动，**不能写成旧版远树完全无碰撞**。V7给可到达树干生成12个高度切片，同时禁用该批次旧重复直柱；冠叶保持可穿行。
- 停栖树枝原始根点从树根竖直投影取得，未精确贴合弯树干。V7从实际树干曲线取得附着点，停栖/光羽/生态目标坐标保持不变。
- 微气候使用内部dt累计时钟，外部时间跳跃或菜单暂停不会让雾继续平移；降低动态保留静态形状。
- 地面使用已有CC0材质，新增宏观湿润斑块、粗糙度变化与较细的法线，不增加网络纹理或独立地表绘制。
- 提供forest.surfaces稳定引用，使traversal/chapter可在图片尚未加载时构造，三者资源可由主入口并行请求；避免通过image.src判断加载顺序。

首轮同机位6景已通过WebGL检查，根穹中央低处净空4.67m，增加的树冠与雾每景约2–8次绘制。此时数据为中间版本，正式统计会在最终报告另列。

- [Giant Squid / Matt Nava 概念艺术](https://giantsquidstudios.com/ABZU-Concept-Art)：参考大轮廓、负形开口、前后层次的组织方法，未复制图片或游戏资产。
- [Journey 官方](https://thatgamecompany.com/journey/)：参考探索中的远方视觉目标、飞越遗迹的情绪组织；不复制模型或音乐。

## 聚落竹影追加设计

三簇细竹位于(.535,-18)、(.592,-20)、(.65,-12)，为田—屋—陶窑提供区别于阔叶森林的轮廓。46根轻弯竹秆、节环和低处干箨、2484片窄长叶合为6次绘制。分枝从节位伸出；368个小半径高度代理在traversal构建前注册。竹丛周围原有粗树以及穿入屋顶/稻田的散布树在生成前剔除，不留碰撞残影。陶案周围保持净空。

竹形参考[蒙特利尔植物园关于竹秆、节间和箨的说明](https://www2.ville.montreal.qc.ca/jardin/en/chine/bambou/chaumes.htm)、[RHS的竹秆/节与披针形叶说明](https://www.rhs.org.uk/plants/types/grasses/bamboo-control)。这是生活材料主题的艺术表现，不识别具体竹种，也不作为金沙古植被复原证据。
