# V7 交互审视与候选方案

2026-11-19。阅读V6实际代码、执行稿、生态验收、声音实现及官方案例后的制作判断。此文件是设计审视，不把尚未实现的候选写成已交付。

## 已有体验与缺口

五境已有携回三芽、离散旋转玉轮、水渠、飞越六环、持续聚光。步行、飞潜、停栖和简单自然边界已经构成完整行动基础。V6的三个生态相遇增加了情绪，却主要共享“达到地点/模式 + Q + 等待计时”的条件；完成后缺少可反复摆弄、拥有个人结果的物件。两组旋转机关同用E逐档切换，也缺少连续控制的触感。

因此本轮优先扩展一种**亲手塑造结果**的动词，少做一个收集计数。叙事从“把光带回来”延伸到“给后来的人留下一件用得上的东西”。它不增加主线门槛、不需要完美反应，也不以文化问答判分。

## 候选与推荐

### A · 泥火留形（推荐第一优先）

聚落已有陶窑和日常生活主题。路侧增加可接近的陶案，E/触屏动作进入原场景近景。沿泥坯高度选位置，横向拖动收放轮廓；键盘上下选高度、左右塑形提供等效操作。变化直接更新真实中空器身，保留器口厚度和底部。三种原创器形轮廓只作灵感，不是必须描出的标准答案。完成后让窑火把湿泥转为烧成色，自己的器物继续留在场景并可回看/重塑。无需新增地图片区。

这里的“留下”要真实进入存档，而非关闭弹窗后丢失。中途退出保存泥坯，重开/旧档不污染主线；烧制演出受暂停与减动态设置约束。文案准确称“以制陶遗存为起点的创作”，不把现代转盘手势冒称金沙制陶工序复原。原场景镜头和主线程控制归主控；模块负责模型、纯状态、输入UI和局部响应。

声音随实际塑形速率出现柔和摩擦/湿泥声，停手即落下；烧成时短促炉火和低金石尾音。可以利用现有本地音轨与音量总线制作，避免每次拖动重复整段完成提示音。

### B · 借日显纹（第二优先）

泥壁或断木上的刻线在不同光向下显现不同层次，肩灯F和玩家绕行/升高改变入射角。借现有侧光与相机朝向，不新增不可理解按键。玩家在平地看见河流片段，走到侧面或飞上枝头才将两层影子对齐。奖励是现场短暂出现的人间记忆，不提供所谓历史事实答案。

工程需保证角度判定与屏幕可见效果一致：单纯按F读条不可接受；至少有两个有意义观察位，低画质仍能看清，减动态不隐藏解法。更适合主控做场景内能力扩展。

### C · 羽风引种（备选）

将玩家的移动/振翼变为局部风场，推动浮种或薄叶穿过低矮苇孔；持续移动可改变弧线、停下种子缓落。轻量有限粒子积分即可，不冒称完整流体。与现有穿环不同，操纵对象为身外的柔软漂浮物，玩家可以玩出不同轨迹。预算风险是碰撞/目标引导/三维输入可读性同时需要调试，若只剩时间应保持为无分数的可玩小景，不塞第三套未打磨任务。

## 已查阅的依据

- [金沙馆方：金沙考古](https://www.jinshasitemuseum.com/info/706)：记述房址、窑址、灰坑与陶器等遗存，可以支撑聚落与制陶主题；本文未据此声称某种具体手势或器形的考古复原。
- [金沙馆方：灰坑保护](https://www.jinshasitemuseum.com/info/1406)：居址周围的灰坑、生活废弃物与陶器为生活层面的叙事提供依据。
- [金沙馆方：植物考古成果](https://www.jinshasitemuseum.com/info/4877)：支持稻作为主的农业背景；漂浮发光种子仍是原创幻想。
- [thatgamecompany：Flower](https://thatgamecompany.com/flower/)：官方介绍强调简单的运动控制与随行动改变的环境。本文转译的是即时因果、易上手与连续变化，而非复制资产/剧情/原作输入。
- [Giant Squid：Introduction](https://giantsquidstudios.com/Introduction)：开发者阐述动态鱼群、角色控制、镜头与水下渲染共同服务体验；V7新交互也应同时考虑声音、镜头和操作，不只画一个新模型。
- [Nintendo：Yoshi’s Crafted World Story](https://yoshiscraftedworld.nintendo.com/story/)：从另一侧再看场景揭露隐藏事物的设计，可转译为“借日显纹”的换位观察。没有复制关卡或美术。

本轮访问用户指定网站：[Farewell Light](https://sael.net/demo/farewell-light/)抓取不可访问，[Showreel](https://showreel.design/)返回403，[MotionSites](https://motionsites.ai/)可读取公开索引。未声称本轮已试玩前两者，旧V2/V6研究保留。馆方陶器导航/node/200本次实际返回金面具内容，故不将其错当陶器证据。

## 集成注意

`main.js`已有mode、resetInput、audio.setPaused、persist、experienceSnapshot、updateNearby、interact和单一渲染循环。新近景工作台应使用主循环，不另起永久WebGL画布；离开后恢复原玩家位置与相机。`journey.js`目前仅保留已知字段，必须显式加入新状态清洗才会持久化。所有新状态须有限、范围受限、不保存执行中计时；旧存档默认空白。

API建议：`createClayWorkshop({scene,forest,traversal,onEvent,saved})` -> `update(dt,context)`、`interact()`、`setActive()`、`snapshot()`、`serialize/restore/reset/dispose()`，另导出纯状态清洗。全游戏实页验证应含真实拖动/键盘、开合/退出/重访、手机尺寸、暂停/减动态、旧档与非法状态、不同形状、器口透空和有限几何。
