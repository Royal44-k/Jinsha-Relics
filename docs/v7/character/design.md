# 烁羽 V7 角色制作方案

## 制作判断

延续三根弧冠、玉青披羽、象牙白胸与一枚心光的识别形象。V6 的短板并非面数，而是同宽羽片、硬块色、翼尖联动过于整齐，以及运动中缺少头部稳定、收腕和尾羽制动。V7 优先改善这些关系，沿用原控制器和脚部 IK。

1. 方向性羽枝纹理、细化纤维与非等宽飞羽；眼眶、眉羽、颈胸覆羽衔接更柔和；修复折翼后平滑法线没有同步转向的问题。
2. 十个成对初级飞羽控制骨和两个尾羽扇骨。飞行上拍收腕、指羽错时开合，滑翔张指，降落/减速展尾；仍以翼根、腕部、羽尖形成一条运动链。
3. 鸟式头部保持/推进的有限幅度运动、飞行倾斜时头部部分反向稳定、尾羽惯性。保持真实脚掌目标与暂停不动。
4. 两档 GLB 保持同骨架、同接口。预算优先维持现有约 10 万/4.5 万三角形，新增细节用已有羽片拓扑和小骨架完成。

## 研究

- [Cornell Lab：羽毛类型与结构](https://academy.allaboutbirds.org/feathers-article/)：覆羽覆盖、初级飞羽不对称且可独立调整、尾羽扇形与转向。仅用于生物形态原则，不复制图片或原作资产。
- [Frontiers 原始研究：鸽的头部稳定](https://www.frontiersin.org/journals/neuroscience/articles/10.3389/fnins.2017.00551/full)：不同状态的视觉/姿态稳定。这里只作风格化表演依据，不声称生理模拟。
- [Universidad de Zaragoza：A Surface-based Appearance Model for Pennaceous Feathers，PG 2024](https://graphics.unizar.es/projects/FeathersAppearance_2024/)：羽毛外观依赖羽枝、羽小枝与遮蔽关系，表面纹理也能表示微结构，不能只把图片贴到平片上。本项目据此把形状、方向法线、根部色阶和柔光分层处理；没有移植论文的 BCSDF。研究代码仅准非商业用途，未下载或使用其代码、场景和模型。
- [Disney Animation：Look Development](https://www.disneyanimation.com/process/look-development/)：先分解形体、细节与材质层，再放入实际镜头反复检查。本轮同时留存局部同灯光对照和游戏机位验证，不以面数代替成片效果。

烁羽仍是金沙铜鸟意象启发的原创幻想角色。所有角色网格与纹理由源程序原创生成；不称高模雕刻、动作捕捉或考古物种复原。

## 第二次近景审视

实机背面暴露出羽片存在但肩背仍呈大块光滑色面的缺点。原因是短羽过度贴合球面法线，且宽羽边缘埋入身体表面。保持既有羽片数量，调整根部离壳量、毫米级拱度与局部法线混合；翼上覆羽沿已有翼核曲面梳理，去除直排羽根形成的梳齿；后脑羽区由整齐横排改为不规则螺旋分布。飞羽由根部玉青向末端象牙色渐变，保持三根弧冠与披羽色彩的识别度。

## 验证

同镜位 V6/V7 正侧背近景；LOD0/LOD1 实页渲染；8 模式骨骼有限；羽指与尾扇响应实测；坡面落足；暂停冻结；口型与眨眼；实际 GLB 体积与三角数；整合后主agent复核首页和游戏镜头。
