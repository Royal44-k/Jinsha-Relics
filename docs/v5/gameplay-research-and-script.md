# V5 · 让林河回应你的行动

研究与方案日期：2026-11-18。供本轮三小时大版本迭代使用；这是设计建议与实施接口，不冒充已经完成的功能。研究范围是官方网站、开发者发布文章、GDC官方讲座摘要及金沙馆方资料；未声称完整试玩或观看了全部演讲。没有复制第三方游戏代码、美术、音乐或角色。

## 1. 现有体验的真正短板

代码依据：`src/v2/main.js` 的 `updateQuest / inspect / updateNearby / interact / finish`、`src/v2/journey.js`、`src/v3/locomotion.js` 与 `traversal-world.js`。

- 已有八种运动状态，但主任务基本不要求利用高度、水深或惯性。玩家学会飞行之后，仍多半只是沿一条路去看五个展台。
- 五件文物的动作循环相同：走近 → E打开弹层 → 转模型/调侧光 → 三选一 → 继续走。问题本身有依据，却替代了冒险行为。
- Q只提供方向提示，F主要是灯光开关；终章四个光点只检测站近按F。玩家很少提出“如果我这样做，世界会怎样”的问题。
- 约413米曲线及两个支路已经可用，但新区域没有改变行动方式；大树、石块与绿雾在不同距离重复，很难从剪影识别已抵达另一块地图。
- 奖励主要是计数和弹窗，已做的动作很少在环境中留下持续结果；重新经过旧区域也缺少新发现。

因此本轮核心不是再增几件道具，而是让**观察 → 尝试 → 世界变化 → 新路径/新知识 → 再探索**成为主循环。图鉴继续承担准确资料；空间玩法承担冒险。

## 3. 金沙主题依据与虚构边界

| 资料 | 可用于游戏的内容 | 必须保留的边界 |
|---|---|---|
| [馆方古环境/遗存介绍](https://www.jinshasitemuseum.com/info/706)记录古河道乌木与大型树根 | 乌木根庭、盘根支路、高低枝台、湿地树林 | 不据此断言某棵游戏树、植物种类或动物群是原址复原 |
| [黄忠小学地点植物考古成果](https://www.jinshasitemuseum.com/info/4877)介绍普通居住聚落，稻为主、粟为辅助 | 稻作生活片段、陶土、水与日常劳动的关系 | 导水槽谜题、农具与木屋形制均为原创，没有证据证明本作机关是古代设施 |
| [九柱遗迹馆方文章](https://www.jinshasitemuseum.com/seardetail/3793)介绍九柱、不同建筑解释，以及测量方向与冬至日出的关系 | 柱影、观景位置、朝向日出的最终视觉构图 | 建筑用途和上部形制有不同假说；游戏不宣称真的重演古蜀祭礼 |
| 现有铜鸟、玉琮、金面、石虎、太阳神鸟的馆藏来源见 `src/v2/journey.js` | 形态观察、材料差异和图鉴知识 | 实物不变成魔法电池；谜题使用“受形态启发的记忆装置”，不把器物功能虚构当史实 |

叙事定位：**烁羽在一段不完整的林河记忆中醒来。它一路让水、风、种子与光重新相遇，最后看见这些平凡生活与古蜀器物如何同在一片土地上。** “修复”指原创记忆世界，不是在现实中搬动遗址、收取文物。

## 4. 一段完整冒险：五幕、四种主行动、一项可重玩挑战

建议主线首次体验目标20–30分钟，含观察与支路目标35–45分钟；这是设计目标，实际时长必须试玩测量，不能作为已经达到的宣传数字。

### 序幕：乌木初醒（原路径0.00–0.14）

画面先压低视线，乌木根洞漏出暖光；天空不先暴露全部远景。脚下出现一枚会回应Q的细小光芽，三步内可以完成首个互动，30秒内必须看见第一次世界变化。

**行动一：拾取与归还。** E拾起光芽，光芽跟随胸前；走到空巢再按E放回。第一次仅一个目标，不混入飞行要求。成功后枝叶从灰绿转暖、数只光鸟穿过根洞，露出高枝上的残页。之后同一动作在水下和高处复用，改变的是空间路径。

奖励：得到“归光”能力规则、第一张行记；主径始终可走，支路高枝可提前探索。第一株树的变化永久保存，回头能认出自己的行动。

烁羽：“它好像在等我……把这点光，送回去吧。”

### 第一幕：听水见鸟（0.14–0.28，深潭中心约0.215）

密树让位于横向开阔的水面、芦荡与低岸；铜鸟在水岸先以剪影出现。Q让水中三点回声短暂显形：浅滩、沉木旁、深潭各一枚记忆光芽。可自行决定搜寻顺序。

**行动二：分层搜寻。** 潜水与上浮真正服务于任务。只需E近身拾取，任务物收取后永久记账，不强迫来回三次运送；最后返回水边落点统一归还。水下至少放一个安全透光水面出口，目标不得藏在比氧气预算更远的位置。

奖励：水光增亮、鱼群散开再汇聚、铜鸟观察点显现；可选支路残页提示“流动的方向，藏在宽窄之间”。文物资料可以现在看，也可稍后从图鉴读。

录忆者：“古河道留下乌木与树根，也留下人们生活的线索。”
烁羽：“上面有风，下面也有一条路。”

### 第二幕：方圆借光（0.28–0.49，断岸0.31、枝台0.365、玉琮0.42）

关卡从水平水面转为明确的竖向结构：断岸、枝台和一组可见光路的木石观察装置。浅蓝冷光与较干燥石面区分前一区。

**行动三：真实空间对齐。** 三个可旋转的装置，每次E转90°，几何与光路同步改变。来自侧方的光只穿过已对齐的孔道，未接通处出现终点光斑，让玩家能观察因果。每一段都有缺口/刻痕作为视觉线索；不可只靠暗藏答案数组和“对了”弹字。

玉琮实物仍是旁边可观察的文物模型，不旋转、破坏或供能。装置是本作虚构的“方圆观察廊”。成功后远方云隙打开、高处支路显现，获得日轮的一段原创光纹。

**可重玩挑战：借风环线。** 从地面起点E开始，经4–6个风环，借上升气流、滑翔、枝台补能完成。第一次无强制限时，只显示环数；完成后开放计时和个人最好成绩。漏环时仍标记上一个未通过的环，不清零、不强制传送。桥始终作为可步行替代，主线不强迫竞速金牌。

烁羽：“不用撞开它。试试，让光自己找到出口。”

### 第三幕：归水生田（0.49–0.65，稻作0.55、木屋0.575、金面0.60）

树冠降低、天空比例增加；材质主角变为稻穗、湿泥、陶土与木梁。地标是可进入的茅屋与一条看得见水流方向的生活沟槽。

**行动四：导水连通。** 三段L形槽可近身E转向，水从上游沿实际相接的槽端传递；未接通时水停在对应节点。玩家沿槽走动观察，不打开抽象连线弹窗。接入田畦后稻穗起身，泥面变湿、局部水纹流动，远处出现暖色炊烟；这些变化随后持续存在。

允许随时继续探索，不用解锁一堵看不见的门。完成带来下一段日轮光纹与一页“人的生活”行记；金面资料页强调材质与开口，与旁边的生活景观形成反差。

录忆者：“遗存告诉我们，这里的人以稻米为主食，也种植粟等作物。”
烁羽：“原来，光不只藏在金子里。稻穗上也有。”

### 第四幕与终章：九柱候日（0.65–1.00，石虎0.77、九柱0.84、日轮0.94）

这里要有最大的视觉变化：低植被、柱影、石纹与开阔河湾，远景从暮青缓慢转为日出暖金。保持“从窄处走到宽处”的揭示；不要把终点日轮变成悬浮UI靶标。

石虎段提供一个可选安静支路：Q唤出沿天然石纹排列的三处光痕，绕行观察可获最后残页。它不再要求第五次同构选择题。

**终章是前面知识的汇合。** 三段光纹到齐后，在九柱观景位E进入一个可退出的短“对景”状态；玩家仍能拖动镜头/触屏转向，把柱间缝隙与日轮对齐。以水平夹角与竖向角的容差判断，持续约1.2秒完成，减少动态模式不强制镜头推进。日轮外圈四鸟先以四段虚线显现，随后原有四处光点可逐一留下光，成为最后一段亲身走过的仪式性收束，而非最主要谜题。

结尾呈现一路的变化：根庭已绿、水面有鱼、稻田起伏，最终烁羽再展翼。给玩家“继续探索”“重试风环”“查看行记”三个动作；不要求重置存档。

录忆者：“九柱遗迹的朝向，与冬至日出的方向相合。它原本如何使用，仍有不同讨论。”
烁羽：“这次，我知道回去的路了。也想看看，还没走过的地方。”

## 5. 地图与支路要有拓扑差异

保留现有413米主路径作为稳定骨架，先不用贸然扩成数公里。每个主题区至少增加一种不同的路网结构：

1. 根庭：小环路，地面入口与高枝回出口互相可见。
2. 水岸：横向扇形分支，岸上/水面/水下三个高度共享目标区。
3. 风口：低桥安全路与高空挑战路并行，末端汇合。
4. 稻作：可自由绕行的工作小院；解水后开出一条视觉明确的小径近路。
5. 九柱：先穿窄廊，再到无密树遮挡的大开敞观景面。

地图界面建议“雾绘行记”：只绘出走过的连续路径和已见地标；未抵达区只留淡轮廓及一条文字问题。不要用五张卡片替代地图变化，也不要一开始显示全部解谜答案。残页奖励位置以“看见但暂时不知道怎么去”的构图布置，至少一处可从出生地仰视看到。

## 6. 交互、失败与奖励规则

- **E始终是近处动作**：拾取、放回、转向、开始挑战、观察，当前只有一个最高优先级提示。物件名称与动词同时显示，距离2.2–2.8米内可用；飞行高速掠过不误触。
- **Q始终是短时回响**：6秒显示当前区域响应物与模糊方向，3秒冷却；必须同时有形状/文字反馈，不只靠颜色和声音。旧倾听入口可以融合，不能同时出现两套相互矛盾的提示。
- **F保留光的身份**：普通探索展开侧光；在明确的日轮落点才留下光。不要让F同时承担拾取、转槽和跳跃。
- 触屏沿用左摇杆、拖动视角、↑/↓；右侧就近动作键显示当前动词。所有空间谜题可用单次点击操作，不要求键鼠独占的瞄准精度。
- 携带物只使用一次一个与明确目标；关键物不会因落水、飞出边界或刷新而永久丢失。恢复时送回最近安全点，光芽已获状态保留。
- 解谜没有“答错扣血”。转错会改变光/水的去向，因此失败本身可学习；提供手动重置装置位置，不重置章节成就。
- 每一次完成都有三层反馈：0.1秒触感/声点；0.5–2秒局部动态因果；2–6秒远景变化或新路径揭示。低动态模式保留最终状态和信息，取消强镜头运动。
- 主线奖励是世界变化与三段光纹；支线奖励是6页行记、观察点和风环个人纪录。不要堆几十个同构发光球。

## 7. 建议给主控的模块接口

下列为建议契约，主控可以调整名称。纯状态逻辑与三维展示分离；全局游戏模式、音频、相机与存档仍由main管理。

```js
// src/v5/adventure.js
createAdventure({scene,forest,traversal,onEvent,saved}) => {
  update(dt,{time,position,motion,camera,playing,reduced,quality}),
  getInteraction() => null | {id,verb,label,detail,position,priority},
  interact() => boolean,  // true: 消耗本次E，不再打开旁边的文物弹层
  pulse(),
  getQuest() => {chapter,title,objective,steps:[{label,done}]},
  getSnapshot(), serialize(), resetPuzzle(id), dispose()
}
```

事件建议：`discovered`、`picked-up`、`deposited`、`puzzle-changed`、`chapter-complete`、`challenge-start`、`challenge-ring`、`challenge-finish`、`hint`、`finale-ready`。每个事件含 `id,text,position`，可选 `sound,caption,worldChange`；不让模块自行打开DOM或调用全局音频。

```json
{
  "version": 1,
  "discoveredZones": ["root-grove"],
  "pages": ["seed-return"],
  "root": {"returned": ["root-seed"]},
  "water": {"found": ["shallow"], "restored": false},
  "light": {"turns": [0,0,0], "solved": false},
  "irrigation": {"turns": [0,0,0], "solved": false},
  "wind": {"completed": false, "bestMs": null},
  "finale": {"aligned": false, "complete": false}
}
```

新字段建议独立存为 `jinsha-adventure-v5` 或扩展旧v2存档的明确验证字段；不能无条件清空旧文物/设置/安全落脚点。内存中的进行中计时不必跨刷新继续，最好成绩和已完成状态要保存。非法数组、重复id、NaN时间、越界旋转值都要规范化。

状态判定建议可测试而非依赖镜头截图：近身交互距离；三维门环穿越平面与半径；槽端连通图；光线分段命中；知识/章节依赖；完成事件只触发一次。调试传送仅在DEV，生产保留只读快照。

## 8. 三小时实施优先级与验收

**必须做成闭环**：至少三类真正不同的场景互动（空间搜寻、旋转连通、飞行路线），能看到持久环境变化；五幕目标明确；旧存档可继续；新增交互可用触屏完成；区域剪影和天空比例有实质差异。

**有余量再做**：携光起步引导、九柱对景终章、行记残页和发现地图。若只有两个模块能完成，要优先一个完整故事闭环，不能用未生效按钮和锁住的占位地点凑规模。

建议节奏：0–20分钟研究/定稿，20–100分钟三线并行制作，100–140分钟整合完整关卡，140–175分钟实际键鼠/触屏、失败恢复、加载与帧时间，最后5分钟确认生产包/实际截图/剩余差距。不是到了分钟就宣称达成；必要时主控及时缩减未闭环的次要功能。

最小验收路径：新开冒险 → 第一次归光 → 游泳/潜水收回光芽 → 转装置看见连续光束 → 飞过有次序的风环并重试 → 调整导水槽使田畦状态改变 → 九柱/日轮终章 → 重载后所有已改变环境保持 → 继续寻找至少一页先前漏掉的残页。每种失败都要真的试一次：错误旋转、漏环、氧气不足、携带时越界、任务中暂停、触屏取消按键。

不可只拍标题和静止风景来验收“可玩性”；应保存一次从目标到操作再到环境改变的连续录屏或序列截图，并记录首次玩家是否能从画面理解下一步。
